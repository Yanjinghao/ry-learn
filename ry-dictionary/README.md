# 前端 → Java 全栈 · 学习计划总览

> 面向：Web 前端转 Java 全栈（Spring Boot 中后台）  
> 节奏：工作日每天约 **3 小时** + **周末**做联调 / 部署 / 验收  
> 原则：前 4 周自己手写后端，第 5～6 周再对标若依，避免「只会改脚手架」

---

## 1. 总目标（6 周）

做出 **2 个可演示** 的作品，面试能讲清登录、权限、事务、部署：

| 作品 | 内容 | 建议完成周 |
|------|------|------------|
| 作品 1 | 自研简易商城：登录 + 商品 + 下单扣库存 + RBAC | 第 4 周末 |
| 作品 2 | 若依二次开发：手写「售后工单」模块并部署 | 第 6 周末 |

---

## 2. 推荐技术栈

| 层 | 选型 | 说明 |
|----|------|------|
| 前端 | Vue3 + Vite + Element Plus | 用你已有的前端能力对接即可 |
| 后端 | Java 17 + Spring Boot 3 + Maven | 第 1～4 周从零手写 |
| ORM | MyBatis-Plus | 先会 CRUD 和自己写 SQL，再谈生成器 |
| 数据库 | MySQL 8 | 第 1 周就要装，表结构自己写 |
| 缓存 | Redis | 第 3 周起，只做一种用途（缓存或登录态） |
| 鉴权 | JWT + 拦截器 | 第 1 周先跑通，第 4 周再上 RBAC |
| 企业骨架 | RuoYi-Vue3（单体） | 第 5 周起；**不上** RuoYi-Cloud |

统一项目习惯：`frontend/` + `backend/`。密钥、数据源只放配置文件或 `.env`（勿提交）。

当前练习仓库建议：

| 周次 | 目录 |
|------|------|
| 1～4 | `D:\workspace\ry\week1_shop` |
| 5～6 | `D:\workspace\ry\ruoyi-vue`（若依前后端） |

---

## 3. 每日 3 小时切分

| 时长 | 内容 |
|------|------|
| 0～20 分钟 | 复习昨天笔记 / 跑通昨天接口 |
| 20～150 分钟 | 主学：写接口、改表、联调或读若依源码 |
| 最后 20 分钟 | 记 5～10 行：今天解决了什么、卡在哪 |

原则：**少看视频多敲**；当天必须有可运行结果（接口通或页面通）。

## 6. 机器与环境约定

| 项 | 约定 |
|----|------|
| JDK | 17 |
| 构建 | Maven |
| 数据库 | 本机 MySQL 8 或 Docker |
| Redis | 本机或 Docker，第 3 周起用 |
| 接口调试 | Apifox / Postman / curl |
| 前端 | Vue3，端口与后端 CORS 对齐 |

第 1～4 周 **禁止**用若依代码生成器当主路径；第 6 周业务模块必须手写。

---

## 7. 明确不做（避免分心）

- 不上 Spring Cloud、若依微服务、K8s
- 不上 Kafka / RocketMQ / Seata
- 不接微信 / 支付宝真实支付（mock 回调即可）
- 不为了「再学一遍 Vue」消耗后端时间；前端只练对接（动态路由、权限指令、字典回显）
- 周末不新开第三个无关项目
